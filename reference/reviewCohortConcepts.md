# Use an LLM to review concepts that led to cohort inclusion

Use an LLM to review concepts that led to cohort inclusion

## Usage

``` r
reviewCohortConcepts(chat, cohortConcepts, clinicalDescription)
```

## Arguments

- chat:

  An ellmer chat

- cohortConcepts:

  Results that include codelist diagnostics

- clinicalDescription:

  A clinical description

## Value

A tibble with concepts reviewed
