# Export cohort expectations to a CSV file

Export cohort expectations to a CSV file

## Usage

``` r
exportCohortExpectations(
  expectations,
  fileName = "expectations.csv",
  path = getwd()
)
```

## Arguments

- expectations:

  Cohort expectations

- fileName:

  Name of the file that will be created.

- path:

  Path where the CSV file should be created.

## Value

NULL. Called to write file to disk
